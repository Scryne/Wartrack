# Data Visualization Skill

## Purpose
Establishes clear, accessible data visualization standards, KPI metric anatomy, chart card hierarchy, and sparkline styling.

## Core Rules
1. **KPI Card Anatomy**: Label (top) → Value (middle, bold/tabular) → Delta (bottom with comparison context). Never invert order. Max 4 cards per row.
2. **Chart Styling**:
   - Clean horizontal gridlines (solid 1px border color, 60% opacity), no vertical gridlines.
   - Hide raw axis lines and tick marks.
   - Area fill: Vertical gradient from accent 12% to 0%. Never solid block fills.
   - Line width: 2px with rounded stroke caps. Data points visible on hover only.
3. **Color-Blind Safe Palettes**: Sequential, distinguishable chart series colors.
4. **Tooltips**: Surface background, subtle shadow, structured header + labeled values with tabular figures.
