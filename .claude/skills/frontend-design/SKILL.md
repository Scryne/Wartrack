# Frontend Design Skill

## Purpose
Establishes strong visual direction, layout hierarchy, typography pairings, and character for frontend components and views without defaulting to generic templates or slop.

## Core Rules
1. **Restraint over excess**: Limit colors to 1 primary accent + neutrals + semantic status colors. Do not use multiple accents or arbitrary gradients.
2. **Typography**: Pair distinctive display fonts with readable body/mono fonts. Avoid plain Poppins/Montserrat/Inter defaults. Ensure full Turkish glyph support (Ğ, ğ, Ü, ü, Ş, ş, İ, ı, Ö, ö, Ç, ç).
3. **Information Architecture**: Structure pages with clear 1st, 2nd, and 3rd level visual hierarchies.
4. **Signature Element**: Provide one memorable signature interaction or visual focal point per major screen.
5. **No AI Tells**: No purple-to-pink gradients, no emoji icons, no overused glassmorphism, no unstyled shadcn templates.
